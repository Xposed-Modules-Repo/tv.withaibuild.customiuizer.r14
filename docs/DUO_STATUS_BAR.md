# Duo 三合一状态栏

适用于 HyperOS 1 / Android 14。入口：系统 → 状态栏 → Duo 三合一状态栏。默认关闭；设置变更后重启系统界面。

外圈是手机电量，顶部是百分比或充电闪电，中间是网络或耳机图案，下方四点是默认数据卡的蜂窝强度。应用、锁屏、控制中心及收起过程使用相同图案。

## 大小与对齐

自动大小按设备原生图标和可用空间适配。双排时在右侧跨两排居中显示，保留完整尺寸，不挤入半行。关闭自动大小后使用手动值；已有手动设置保留。可选线条加粗。

默认在可用内容区域内居中，垂直微调范围±4dp，每档0.5dp。偏移受实际可用高度限制，边界处自动缩小留白，适应双排和自定义状态栏高度，避免裁切。

## 网络与耳机

- Wi-Fi 一格只点亮圆角三角底部，二格增加内弧，三／四格增加外弧；淡色部分是未点亮的轨道。
- Wi-Fi 未连接时默认显示蜂窝或无服务图案；可关闭替代，恢复淡色 Wi-Fi。蜂窝图案只表示有服务，不代表互联网可用。
- 蓝牙音频新连接提示3秒，然后恢复网络图案；初始同步、重复事件及重新打开控制中心不会重播。有线耳机保持显示。
- 耳机样式可选按连接方式、头戴、耳塞，大小85–115%。默认蓝牙用耳塞、有线用头戴；不识别具体耳机型号。
- 有明确的新系统电量报告时，蓝牙耳机≤20%为红色、≤50%为琥珀色。蓝色表示蓝牙，也包含未知电量，不表示满电。多设备或数据缺失时保持蓝牙色；有线耳机没有虚构的电量，外环始终是手机电量。
- Wi-Fi 网络异常优先于耳机提示；无 Wi-Fi 的飞行模式优先显示飞机。原有独立蓝牙／耳机图标仍遵守原有设置。

## 颜色与过渡

普通前景跟随原生状态栏颜色和透明度。充电绿色、省电黄色、手机低电量红色属于提示色；蓝牙色兼顾深浅背景。

中间图案使用约180毫秒的淡入与轻微缩放。省电、系统关闭动画或关闭短过渡时直接切换。快速变化不叠加动画，隐藏时停止，静止时没有持续刷新。

## 使用与参考

Duo 的百分比、尺寸和微调独立于原生电池样式。手动尺寸与自动尺寸互斥；耳机样式、大小和电量颜色依赖耳机提示开关。接口不兼容或运行异常时恢复原生显示。

参考 [Duo Status Bar](https://github.com/kvmy666/duoStatusBar) 与 [Status Trio](https://github.com/lingyired/status-trio) 的图形，以及 [DuoBar](https://github.com/Mikeli7666/DuoBar) 的短连接提示。Wi-Fi 矢量来源和 Apache-2.0 许可随包提供。仅使用原生绘制，无额外动画运行库、轮询服务或后台线程。

[Apple 的公开介绍](https://www.apple.com/newsroom/2026/09/apple-unveils-iphone-duo/)未说明 Wi-Fi 关闭后中间图案的完整规则，本模块的断连替代是可选增强。系统不提供耳机电量时无法推断。短时本机验证不代表全部机型、耳机或长期耗电表现。
