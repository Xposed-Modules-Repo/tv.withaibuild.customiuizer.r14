## 本版变化

自 r14.27.9 起的变更：

- **控制中心**。修正下拉交换手势，完善自定义磁贴列数和横竖屏分栏。
- **状态栏**。双排双卡可独立更新副卡信号，网速跟随系统刷新和清空。
- **音量与亮度**。百分比跟随原生进度，扩展勿扰计时器沿用系统控件。
- **桌面**。调整图标标题、文件夹布局和桌面双击与原生桌面的衔接。

升级后重启桌面和 SystemUI。

## 安装与兼容

1. 下载并安装正式 APK；同签名覆盖安装保留应用数据。
2. 在 Xposed 框架中启用模块并选择所需作用域。
3. 重启相关进程或设备，按设置页提示启用功能。

其他 Android / HyperOS 大版本不在支持范围内。请勿与上游或其他 CustoMIUIzer 派生模块同时启用。
