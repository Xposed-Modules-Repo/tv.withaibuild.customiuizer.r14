## 本版变化

自 r14.26.11 起的变更：

- 新增默认关闭的 iOS 最近任务堆叠，支持已适配 HyperOS 1 桌面的横向最近任务及横竖屏显示；保留原生滚动、任务关闭与窗口交接。
- 堆叠卡片支持大小调整，标题和图标独立缩放并按深度淡出；提供可关闭的窗口动效，按原生接口适配两类桌面窗口实现，取消精确版本号限制，并补齐旧版 POCO 的窗口弹簧接口；缺少可选动效接口时保留原生时序。
- 修正堆叠卡片在拖动、删除、取消及返回时的前后遮挡、窗口圆角衔接和过早回收；横向甩动增加方向吸附。不支持的布局恢复原生命中、输入与滚动边界。
- 新增默认关闭的 iOS 手势指示条，沿用系统显隐、颜色与手势输入；按原生绘制能力准入，不再限定设备和构建号。需启用全面屏手势、保留系统指示条并重启系统界面。
- 新增 iOS 音量条外观，支持横竖屏、连续圆角和原生阴影；收细时向屏幕边缘靠近，连续按键保持细条，触摸拖动时放大。保留系统位置、音量档位、路由、静音状态及展开控制。
- 新增音量条“默认窄条”开关，可直接以细条出现并在触摸调节后返回细条；底部三点随形态合为单点，修复展开入口首次点击只获取焦点的问题。
- 音量填充跟随原生动画，移除边缘深色叠绘；补齐最大 / 最小音量的按键反馈、触摸过拖与释放回弹，并平滑处理细条端帽。
- 动态岛细化伸缩、小岛、内容切换及按压反馈，支持动画中连续改向；缩短多活动交接等待，已有岛体保留旧内容至新活动接触阶段，恢复响铃时加入横向摇动与回弹。
- 调整吸入效果的头部收束与岛体承接，移除液面凹陷、头部透明和额外纵向负压缩，避免接收阶段重复激发整段岛体；保留原生返回轨迹、弹簧、呼回和画中画交接。
- 修正顶部挖孔保留区影响自动高度及相机遮罩的问题；恢复音乐岛最终退出时序，减少末尾半透明残留，并修复较大字号、较矮岛体下普通 Toast 的适配。
- 系统提示优先显示实际功能 / 模式，空间允许时显示次级状态；文字按可用区域显现，取消额外字号脉冲。同一通知更新时保留已显示内容，旧点击动作立即失效，隐私状态仍实时核验。
- 实时活动补齐初始前台状态，原生单例查询不可用时仍保留前台变化观察；横屏响铃时动态岛暂时避让原生闹钟 / 计时器窗口，结束后恢复。清理异常也会完成状态栏解绑。
- Duo 更新蜂窝、Wi-Fi、飞机与耳机图形排列，调整百分比 / 闪电避让和四点圆弧对称；保留原有大小、偏移、间距及耳机缩放设置。状态栏小型 HD / 漫游图标按实际字段处理，缺失时局部跳过，移除多余的地区限制。
- Duo 数字与网络标签改用获许可的相近圆体，网络文字加粗跟随现有开关；微调自动大小、中央 Wi-Fi 图形比例及状态切换动效。
- 控制中心点击后自动收起时，避免随后重复弹出该次操作的状态提示；操作失败仍保留原生反馈。修复音量面板原生刷新后隐藏静音 / 勿扰按钮选项失效的问题。
- 修复旧设置分类恢复时页面为空，音量与最近任务选项继续进入当前页面；简化部分功能名称、补齐多语言文案，保留既有设置键、搜索、备份和升级兼容。

## 安装与兼容

1. 下载并安装正式 APK；同签名覆盖安装保留应用数据。
2. 在 Xposed 框架中启用模块并选择所需作用域。
3. 重启相关进程或设备，按设置页提示启用功能。

其他 Android / HyperOS 大版本不在支持范围内。请勿与上游或其他 CustoMIUIzer 派生模块同时启用。
