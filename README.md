## 本版变化

自 r14.27.1 起的变更：

- 改善 DECK 横竖屏衔接、卡片跳动与阴影闪现，避免手势条快速切换时误用堆叠缩放。
- 动态岛上岛与内容切换更连贯，长岛文字更贴近摄像头保护区。
- iOS 手势指示条黑白切换更柔和，功能开关更易搜索；精简 Duo 等设置说明。
- 更新后重启桌面与系统界面。DECK 需将最近任务排列设为“横向”。

## 安装与兼容

1. 下载并安装正式 APK；同签名覆盖安装保留应用数据。
2. 在 Xposed 框架中启用模块并选择所需作用域。
3. 重启相关进程或设备，按设置页提示启用功能。

其他 Android / HyperOS 大版本不在支持范围内。请勿与上游或其他 CustoMIUIzer 派生模块同时启用。
