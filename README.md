## 本版变化

自 r14.27.5 起的变更：

- 新增按应用切换系统定位的功能，支持名单模式和从最近任务移除卡片后自动关闭。
- 统一 DECK 的桌面和应用入口布局，改善重叠卡片的阴影和窗口交接。改善桌面文件夹模糊过渡，并可调整动态岛吸入时的页面头部宽度。
- 调整 Dock、底部手势条和 iOS 音量样式的状态管理。

## 安装与兼容

1. 下载并安装正式 APK；同签名覆盖安装保留应用数据。
2. 在 Xposed 框架中启用模块并选择所需作用域。
3. 重启相关进程或设备，按设置页提示启用功能。

其他 Android / HyperOS 大版本不在支持范围内。请勿与上游或其他 CustoMIUIzer 派生模块同时启用。
