## 本版变化

面向 HyperOS 1 / Android 14 的阶段性稳定版。

- **桌面与导航**。DECK、Dock 和 iOS 手势指示条接入原生窗口与手势。
- **系统体验**。动态岛统一活动与提示，状态栏、通知栏媒体和音量提供可选样式。
- **自动化与设置**。定位、Wi-Fi、VPN 和应用行为支持规则配置，保留现有偏好和备份。

升级后重启桌面和 SystemUI。

## 安装与兼容

1. 下载并安装正式 APK；同签名覆盖安装保留应用数据。
2. 在 Xposed 框架中启用模块并选择所需作用域。
3. 重启相关进程或设备，按设置页提示启用功能。

其他 Android / HyperOS 大版本不在支持范围内。请勿与上游或其他 CustoMIUIzer 派生模块同时启用。
