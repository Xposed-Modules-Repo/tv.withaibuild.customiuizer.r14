## 本版变化

自 r14.25.9 起的变更：

- 设置界面全面迁移到 Compose，统一列表、搜索、选择器、滑杆、颜色和动作编辑器的布局与状态反馈；保留既有设置键、备份和功能行为。应用行为、Wi-Fi 与 VPN 自动化集中到「系统 → 应用与自动化」。
- 首页搜索默认收起，展开后独立呈现、自动聚焦并高亮匹配词；修复焦点残留和键盘闪现，返回与后台恢复行为一致。应用选择器在没有查询时直接使用已有数据，减少不必要的后台派发和空列表交接。
- 页面、顶栏和卡片统一为中性深浅色，按钮、开关和滑块使用 Material 3 动态取色；状态栏与导航栏同步页面背景，三点菜单统一字体与配色，为重启子菜单增加轻量切换过渡，并在页面 / 菜单离场时清除按压反馈，避免深色点击状态随页面移动或残留。
- 修复界面语言、系统设置入口位置等选择弹窗显示「null」标题的问题，共用标题回退同时覆盖文本与多选编辑器。选项文字采用 16sp 主文字层级，提高可读性并跟随系统字号。
- 手动输入数值时自动全选当前值，增加输入弹窗与键盘的留白，长内容支持滚动，保留取消不保存的行为。
- 补齐应用与自动化入口的分组标题，统一设置分组层级；恢复原生列表边缘拉伸，使用适合运动的文字渲染，减少滚动、回弹和页面切换时的字距与字形微跳。
- 修复 Dock 在隐藏、锁屏后恢复时原生模糊透明度没有恢复的问题，稳定状态不再重复提交相同透明度。
- 新增「系统 → 应用与自动化 → Wi-Fi 自动设置」：按 Wi-Fi 名称、可选 BSSID 和优先级切换勿扰、铃声、自动旋转及 VPN；退出时按所有权恢复，不覆盖已观察到的手动修改。需授予网络身份相关权限，首次启用后重启设备。
- 新增「系统 → 应用与自动化 → 应用行为」：为所选应用启用传感器旋转、媒体音量记忆、固定或跟随系统亮度，以及限制或忽略应用亮度请求；支持精确 Activity 例外。各项默认关闭，首次启用后重启设备。
- 移除 Dock「轻量玻璃」，保留纯色面板与磨砂玻璃；旧轻量玻璃取值自动回退到面板。删除专属渐变描边、额外绘制和模糊 / 省电监听，保留布局、编辑、拖动与解锁行为。更新后重启桌面。
- Wi-Fi 自动设置在退出场景恢复失败时保留有限恢复依据，读回确认后才释放；尊重手动修改与用户切换。网络记录溢出可在完整可信快照后恢复，应用旋转与亮度 Hook 的接口准备相互隔离；修复部分框架缓存旧值导致应用行为和 Wi-Fi 规则修改未及时生效。
- 恢复动态岛波形的流畅显示：显示更新跟随屏幕帧，音乐采样与录音电平恢复此前节奏；保留隐藏停采、实测静音 / 稳定停帧、暂停与省电限制；修复系统动画重新开启后轻量波形无法恢复。
- 动态岛只维护实际受遮挡节点的透明度，静止几何跳过重复遮挡查询，并收紧完整过渡画面的纹理预算；保留原生手势与动画交接。
- 未使用天气内容的时钟停止天气专属订阅与查询；隐藏的第二时钟跳过无输出的刷新。
- 状态栏网速镜像合并重复送达，充电提示只在内容或布局条件变化时更新排版；触摸入口避免无关的亮度读取和整组参数复制。
- 修复录音持续活动在静音后残留旧电平的问题；读取失败后清除旧包络状态，避免沿用错误峰值。

2. 在 Xposed 框架中启用模块并选择所需作用域。
